# FramePilot releases

Desktop installers for [FramePilot](https://framepilot.app), the desktop video editor with an AI
agent that edits your timeline.

**[Download the latest release →](https://github.com/rojan-labs/framepilot-releases/releases/latest)**

Each release lists installers for macOS (Apple Silicon and Intel), Windows and Linux, with
SHA-256 checksums and first-launch steps. FramePilot checks this page for new versions when it
starts.

This repository holds releases only. To report a problem, email hello@framepilot.app.
